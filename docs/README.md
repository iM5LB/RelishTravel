# RelishTravel Documentation

![RelishTravel](assets/RelishTravelRaw.png)

Official documentation for **RelishTravel** — safe, controlled Elytra launch and boost for Paper 1.20+.

## What is RelishTravel?

RelishTravel improves Elytra flight with:

- Charge-based launching (sneak + jump, land to charge, release to launch)
- Mid-air boosting with permission-based limits
- Safety features (fall/kinetic protection, obstruction checks)
- Visual feedback (particles, sounds, action bar)
- Chestplate auto-swap / virtual Elytra options
- English and Arabic language support

Open source and free on [GitHub](https://github.com/iM5LB/RelishTravel) and [Modrinth](https://modrinth.com/plugin/relishtravel).
